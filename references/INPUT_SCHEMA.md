# 输入 Excel 列契约

引擎读取 Excel 的**第一个工作表**，按 `config.yaml → input.columns` 的映射取列。表头必须在第 1 行，列名须与配置中右侧字符串**完全一致**（含空格也需一致）。

## 1. 必需列

| 内部字段 | 含义 | 配置示例值 | 缺失后果 |
|---|---|---|---|
| `name` | 学生姓名 | `姓名` | 无法生成学生行，报错退出 |
| `sid` | 学号 | `学号` | 留空显示 `-`，不报错 |
| `rank` | 用于层次折算的校内排名 | `校内排名` | 该生层次标为 `missing_tier` |

## 2. 学科总分列

在 `input.columns.totals` 下，每个学科分别给每个考试一个列名：

```yaml
totals:
  语文: {期初: "语文期初", 期中: "语文期中"}
```

约定：考试名来自 `config.exam_chain`，必须与这里的键一一对应。若 `exam_chain` 只有一项，则每个学科只填一项。

- 总分列单元格应为数值；空值或文本会被视为缺考（显示 `-`，不参与均分）。
- 学科名（如「语文」）必须与 `config.subjects` 的 key 完全一致。

## 3. 板块得分率列（选填）

在 `input.columns.section_rates` 下，按学科 → 考试 → 板块给出列名，单元格填**百分数数值**（0–100，不带 `%` 号）：

```yaml
section_rates:
  语文:
    期中: {阅读: "语文阅读率期中", 作文: "语文作文率期中"}
```

- 不填此段：跳过「能力摘要」的板块得分率表，「薄弱诊断」列会显示「未配置板块数据」。
- 板块名必须与 `config.subjects.<学科>.sections` 的 key 一致。
- 得分率用于诊断排序，不用于层次折算（层次只看 `rank`）。

## 4. 可选：客观/主观分列

如需在学生分层表显示「客观/主观」列，可在列契约里追加（配置中未列出时该列不生成）：

```yaml
input:
  columns:
    extra:
      客观: "英语客观"
      主观: "英语主观"
```

## 5. 数据清洗规则

- 姓名列为空的行直接跳过。
- 排名列为空或非数值 → 层次标为 `missing_tier`。
- 所有数值列允许空值，空值在报告中显示 `-`，不计入均分。
- 重复姓名**不会**被自动合并；请确保姓名唯一，否则报告与 HTML 会各出现一行。

## 6. 虚构示例

运行 `python scripts/make_sample.py --config config.yaml --out sample.xlsx` 可生成一份与配置列契约完全对齐的虚构数据（姓名为「示例学生01」这类占位符，成绩为随机生成）。可用它先跑通全流程，再替换为真实数据。
