# 折算与诊断规则定制

## 一、折算规则怎么定

引擎的层次折算本质是**区间映射**：

```
校内排名 r  →  从上到下找第一条满足 r <= max 的规则  →  命中层次 tier
```

### 制定步骤

1. **拿本校近 2–3 年的高考出口数据**：统计"校内排名 X 名大致对应全省哪一段位次"。
2. **定档位**：一般 3–5 档即可，档位过多会失去指导意义。例如前 50 / 前 150 / 其余。
3. **填 max**：每档的上界排名。`null` 兜底放最后。
4. **写 desc**：一句话说明该档的经验含义，避免写成精确承诺。

### 重要提醒

- 校内排名是**校内坐标系**，不能直接等同于全省位次；必须经经验折算。
- 报告会自动附免责声明：折算为估算值，仅供学情预判参考，不构成录取保证。
- 不同学校、不同年份的出口差异很大，**请使用者用本校数据校准**，不要照搬示例值。

## 二、诊断归因怎么配

`weak_reasons` 把板块与归因/建议挂钩：

```yaml
weak_reasons:
  作文:
    cause: "审题与结构训练不足"
    advice: "每周一次限时提纲训练"
```

引擎逻辑：对每个学生，取其**期中得分率最低**的板块，查 `weak_reasons`；命中则填 cause/advice，未命中用 `default_reason`。

### 编写原则

- `cause` 写可观察的行为（"审题与结构训练不足"），不要写天赋判断。
- `advice` 写可执行的动作（"每周一次限时提纲训练"），带频率或量化目标。
- 板块名必须与 `config.subjects.<学科>.sections` 完全一致，否则查不到。

## 三、交互 HTML 定制

HTML 由 `build_report.py` 内的模板生成，单文件、无前端依赖。常见改动：

| 想改什么 | 改哪里 |
|---|---|
| 主题色 | 模板 CSS `:root` 的 `--mint` 系列变量 |
| 每表筛选栏 | `renderTable()` 中 `if(cfg.filter)` 分支 |
| 新增加一列 | 对应学科的列定义列表 + `fmt()` 加类型分支 |
| 层次标签颜色 | `tierClass()` 与配置里的 `color` |

## 四、扩展个人 PDF 联动

1. 自行生成每生一份 PDF，命名为 `config.pdf_report.filename_pattern`（如 `report_张三.pdf`）。
2. 把 PDF 放进 HTML 输出目录。
3. 配置 `pdf_report.enabled: true`。

引擎会在表格加「查看报告」列，点击用 `iframe` 内嵌预览。若需按页跳转，URL 用 `file.pdf#page=N`，且切换学生时**重建 iframe**（仅改 hash 在 `file://` 下不一定重新定位）。
